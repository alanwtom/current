# Code of Conduct

Current is maintained by one person. This document exists because GitHub asks
for one and because it is better to have said this before it is needed than
after — not because anything has happened.

## The short version

Be decent to people. Argue about the work, not about the person doing it.

## What that means here

**Welcome:** disagreement, strong opinions about design, "this is wrong and
here's why", bug reports that say the app is broken, and pull requests that
throw out an approach I was attached to. This project has opinions and expects
them back.

**Not welcome:** harassment, personal attacks, demeaning comments about who
someone is — including their identity, background or ability — unwanted
attention, publishing anyone's private information, and persisting after being
asked to stop.

The line is not politeness. A blunt technical review is fine. Contempt for a
person is not.

## Where this applies

Everywhere the project happens: issues, pull requests, discussions, commit
messages, and anywhere someone is representing Current in public.

## Reporting

If someone's behaviour here is a problem, tell me. Use GitHub's **Report
abuse** on the comment or account in question — that reaches both GitHub and
me — or contact me through my GitHub profile.

Reports are read privately, and I won't share who reported what.

## What I'll do about it

I maintain this alone, so there is no committee and no appeal process. I'll
read what happened, and then depending on how serious it is: say something,
edit or delete the content, lock the thread, or block the account. Anything
that looks like a threat or targeted harassment goes to GitHub as well, since
they can act beyond this repository and I can't.

I'd rather be clear about that limitation than imply a process that doesn't
exist.

## Scope note, because it comes up

Requests for content — asking where to download something, or for help finding
it — aren't a conduct problem, they're just out of scope. Current has no
search, no trackers and no indexes. Those issues get closed unanswered; see the
[Scope](README.md#scope) section.
